# Manuscript Revision and Response to Reviewers

## Workflow

1. Collect the decision letter and all reviews. Split every comment into a numbered, atomic item so none is overlooked.
2. Triage each item: valid and requires new analysis or experiment, valid and requires text change, misunderstanding caused by unclear writing, or disagreement. Treat apparent misunderstandings as signs the text needs clarifying.
3. Plan work before writing responses. For requested analyses, run them for real (see `data-analysis` and `statistical-analysis`) and report the result whichever direction it goes. If a requested experiment is infeasible, explain why and offer an alternative, such as a limitation statement.
4. Draft the response letter as: thank the reviewers briefly, then for each comment quote it, answer directly, and point to the exact change with its location in the revised manuscript. Keep a polite, factual tone.
5. Where you disagree, give evidence and reasoning, cite sources, and still concede reasonable points. Never dismiss or mock a reviewer.
6. Keep consistency: the changes described in the letter must exist in the text, figures, tables, and supplementary files, and the numbers must match everywhere.
7. Provide a tracked-changes version and a clean version when required, and update the abstract, conclusions, and reporting checklist as needed.
8. Do a final pass to verify that every item has a response and every claimed change was made.

## Deliverable

A response letter with each comment mapped to a response and location, a list of new analyses and their results, and a change log. Never claim an analysis or edit that was not actually done, and never invent data to satisfy a reviewer.
