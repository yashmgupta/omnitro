# Reporting Guidelines

## Choosing a guideline

Match the guideline to the study design, then confirm the current version and extensions on the EQUATOR Network or the guideline's own site.

| Study type | Typical guideline |
| --- | --- |
| Randomized trial; trial protocol | CONSORT; SPIRIT |
| Observational cohort, case-control, cross-sectional | STROBE (RECORD for routinely collected data) |
| Systematic review or meta-analysis; protocol | PRISMA; PRISMA-P |
| Diagnostic accuracy | STARD |
| Prediction model development or validation | TRIPOD (including AI extensions) |
| Animal experiments | ARRIVE |
| Case report | CARE |
| Qualitative research | COREQ; SRQR |
| Economic evaluation | CHEERS |
| Tumor marker prognostic studies | REMARK |
| Genomic assays and microarray/sequencing metadata | MIAME; MINSEQE |

## Workflow

1. Identify the design from what was actually done, not from the title. Use the extension that fits (for example cluster or non-inferiority trials).
2. Obtain the current official checklist rather than reciting items from memory.
3. Map each checklist item to the exact manuscript location (section and line or paragraph). Mark each item as reported, partly reported, not reported, or not applicable with a reason.
4. For missing items, either add the information if the authors have it or state the limitation. Do not invent details such as randomization method, blinding, or ethics approval.
5. Report which checklist and version were used. Say "checked against" rather than "compliant" unless the authors confirm every item.

## Deliverable

A table of items, status, and location, followed by a prioritized list of gaps and suggested wording for authors to verify. Flag items that need author-supplied facts.
